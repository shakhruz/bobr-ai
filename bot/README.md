# Бобр ИИ — MVP Telegram-бота (математика 5 класса через «учи другого»)

Ребёнок — «устоз», который учит игрушечного **Бобра**. Если ребёнок застрял или объяснил неверно, приходит **Хумо** (птица счастья) и помогает вопросами по методу Сократа. Тема MVP: дроби, сложение с разными знаменателями. Заготовки: десятичные дроби, проценты.

## Запуск за 5 минут
1. Токен бота: в Telegram откройте @BotFather → `/newbot` → скопируйте токен.
2. Ключ Anthropic: console.anthropic.com → API keys.
3. В папке проекта:
```
python3.11 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # вставьте BOT_TOKEN и ANTHROPIC_API_KEY
python bot.py
```
Модель — `ANTHROPIC_MODEL` в `.env`. По умолчанию `claude-sonnet-5-5` (быстро и недорого для диалога). Дешевле: `claude-haiku-5-5`. Умнее: `claude-opus-5-5`. Thinking не включается, `max_tokens` 400, `ANTHROPIC_EFFORT=low`.

Тесты (без сети): `pytest tests`.

## Как устроено
- `router.py` — правила: команды; «bilmayman / не знаю / yordam / помогите / tushunmadim» → Хумо; два неверных объяснения подряд → Хумо; иначе Бобр. Поверх правил — LLM-классификатор (`prompts/router.md`): оценка объяснения верно / неполно / неверно / не знает + тип ошибки + «что Бобр понял» (выжимка) + флаг тревоги.
- `engine.py` — сценарий: знакомство → Бобр просит научить → объяснение → Бобр решает НОВУЮ задачу строго по выжимке (`bobr_belief` в БД): неверное объяснение даёт неверное решение (ответ проверяется кодом, не моделью) → при верном — «контрольная» из 3 задач, зачёт при 2 из 3.
- Хумо: лестница подсказок (наводящий вопрос → про метод → похожий пример → разбор вместе), ответа не даёт; тревожное — «расскажи взрослому».
- `db.py` — SQLite: student, topic_progress, mistakes, messages. `/report` — сводка для родителя/учителя.
- Команды: `/start /help /humo /topic /report /reset`.

## Демо для жюри (8 шагов, ~5 минут)
1. `/start` → Бобр знакомится, ребёнок пишет имя (только имя, фамилию бот не берёт).
2. Цель: «kasrlarni tushunmoqchiman». Бобр: «Ustoz, meni oʻrgat!» и приносит 1/2 + 1/3.
3. Намеренно объясните НЕВЕРНО: «suratlarni qoʻshamiz, maxrajlarni ham» → Бобр честно получает 2/5 и спрашивает, правильно ли.
4. Покажите `/report`: в «Bobr nimani tushundi» видна неверная выжимка — Бобр учится именно из слов ребёнка.
5. Снова неверно (или напишите «bilmayman») → приходит Хумо: вопрос, не ответ.
6. Ответьте Хумо; Хумо поднимается по лестнице подсказок.
7. Объясните верно: «umumiy maxrajga keltiramiz, suratlarni qoʻshamiz, qisqartiramiz» → Бобр решает новую задачу верно.
8. Бобр сдаёт контрольную (3 задачи), результат = качество объяснения. Тема засчитана; `/report` показывает прогресс и ошибки.

## Что сказать жюри о методе
Эффект протеже (protégé effect): объясняя другому, ребёнок сам разбирается в теме. Бобр не знает больше ребёнка и применяет ровно то, что услышал, поэтому ребёнок сразу видит последствия своих слов: объяснение проверяется не оценкой, а результатом Бобра. Ошибки не стыдны: ошибается «ученик». Помощь не подменяет мышление: Хумо ведёт вопросами, а не отвечает. Безопасность: ребёнка не спрашивают фамилию, адрес, школу, телефон; на тревожное — тёплый ответ и «скажи взрослому».

## Ограничения MVP
Не проверено на живом Telegram и API (см. сообщение сдачи). Полностью готова одна тема. Узбекские тексты промптов и фраз нужно вычитать носителем. Один процесс, SQLite без блокировок — для демо и небольшого класса. Для production на `claude-sonnet-5-5` стоит включить серверные `fallbacks` (бета `server-side-fallback-2026-07-01`) на случай отказа по классификаторам безопасности; сейчас отказ обрабатывается дружелюбным сообщением.
